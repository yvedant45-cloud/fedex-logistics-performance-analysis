# 📦 FedEx Logistics Performance Analysis

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of logistics and supply chain operations using the SCMS Delivery History dataset in a FedEx business context.

The objective is to analyse shipment patterns, delivery performance, freight costs and vendor-related activities to identify meaningful trends and business insights.

## 🎯 Project Objectives

- Analyse shipment distribution across countries and shipment modes.
- Understand freight cost patterns and shipment characteristics.
- Examine delivery time differences and delivery performance.
- Explore relationships between shipment quantity, value, weight and freight costs.
- Identify opportunities to improve logistics operations.

- Delivery Performance Analysis

- Correlation between Numerical Variables

## 💡 Key Findings

- Air was the most frequently used shipment mode, followed by Truck.
- Freight costs showed a highly right-skewed distribution.
- Line Item Quantity and Line Item Value showed a strong positive correlation.
- Delivery performance varied across shipment modes and countries.
- Shipment activity and freight costs varied over time.
